# 优化实施记录

基于《优化文档-无登录数据隔离与生成链路修复》执行。

## 已确认口径
- 匿名可写，匿名身份由服务端签名 HttpOnly Cookie 派生。
- 登录身份与匿名身份不自动合并。
- 历史空归属项目作为全员可见、后端强制只读的演示项目。
- 回滚通过复制目标内容创建新版本实现。
- AI 代码生成继续采用异步三阶段流水线，使用 `gpt-5.4`。

## Images to Generate

## 最终验证
- 匿名身份由服务端签发并校验 HMAC Cookie；登录身份使用平台认证 subject，项目域路由统一执行归属过滤，越权统一返回 404。
- 历史 `owner_key IS NULL` 项目作为全局只读演示数据展示；生成、删除、取消、恢复等写入口由后端拒绝，前端同步隐藏或禁用操作。
- 三阶段生成保持异步受理，增加 180 秒模型超时、429/超时/连接/5xx 退避重试、401/403 快速失败、空内容及截断分类、上下文预算和结构校验。
- 回滚通过复制历史成功版本生成新版本，原历史不变；后续增量自然选择新回滚版本作为最新成功基线。
- Preview 与源码共用同一 HTML 状态；版本切换先清空旧内容，并显示一致的版本、长度和短哈希标识。
- `pnpm run lint` 与 `pnpm run build` 通过；后端 `py_compile` 通过；`python -m pytest -q` 共 36 项通过。
- 自动界面截图服务此前未返回图像，因此正式发布前仍需在 App Viewer 人工复核双会话、登录回调和真实模型生成，并使用 Publish 完成部署。
